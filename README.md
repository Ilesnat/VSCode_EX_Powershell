# HelloWorldPS

This extension runs a PowerShell command automatically on startup or via the command palette.

## Features

- **Automated PowerShell:** Runs `Write-Host 'Hello World'` using a background child process.
- **Manual Trigger:** Use the Command Palette (`Ctrl+Shift+P`) and search for `PS: Say Hello World`.

## Requirements

- Windows with PowerShell installed.
- VS Code version 1.90.0 or higher.

## Extension Settings

This extension currently has no configurable settings.
